# 🌐 IP Intelligence & Network Analysis Dashboard

An interactive web-based platform for analyzing and investigating IP addresses. The application provides detailed IP intelligence, including geolocation, ISP and ASN information, DNS and subnet analysis, network telemetry, port checks, threat assessment, and interactive visualizations.

## 🚀 Features

- 🔍 **IP Address Lookup**  
  Retrieve detailed information for IPv4 and IPv6 addresses.

- 📍 **Geolocation Analysis**  
  Identify the approximate country, region, city, timezone, and geographical location associated with an IP address.

- 🌐 **Network Intelligence**  
  Analyze ISP, ASN, hostname, and other network-related information.

- 🧭 **Interactive Maps**  
  Visualize IP locations using an interactive map interface.

- 🔗 **DNS & Subnet Analysis**  
  Perform DNS lookups and inspect subnet-related information.

- 🔌 **Port Analysis**  
  Check network ports and analyze their accessibility and reachability.

- 🛡️ **Threat & Risk Assessment**  
  Analyze IP-related risk indicators and display relevant security intelligence.

- 📊 **Data Visualization**  
  Present network and IP intelligence using interactive charts and analytics.

- ⚖️ **IP Comparison**  
  Compare information and network attributes across multiple IP addresses.

- 📜 **Search History**  
  Maintain a history of previously analyzed IP addresses for easier investigation.

- 📤 **Report Export**  
  Export IP intelligence and analysis results in JSON and CSV formats.

- 🎨 **Responsive User Interface**  
  Provides a modern, responsive interface with customizable themes.

### Frontend

- Leaflet – Interactive Maps
- Recharts – Data Visualization
- REST APIs – IP Intelligence and Geolocation Data
